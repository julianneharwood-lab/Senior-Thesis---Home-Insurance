# Senior-Thesis---Home-Insurance
Code relating to my senior essay examining home insurance premiums and mortgage distress along Florida-Georgia border
# Reinsurance-Driven Insurance Premiums and Mortgage Distress: A Florida–Georgia Border Difference-in-Differences

Undergraduate senior thesis research (economics), Yale University — in progress, expected completion December 2026. This repository is a cleaned, trimmed-down coding sample drawn from the thesis's escrow-burden and mortgage-distress analysis; it is not the complete thesis codebase (see **Scope**, below).

## Research question and design

Rising, reinsurance-driven home insurance premiums in Florida should raise homeowners' monthly costs and, potentially, their risk of mortgage distress. Physical climate risk is roughly constant across the Florida/Georgia state line, but insurance-market structure differs sharply, so the FL/GA border functions as a natural experiment: Florida border counties are treated, Georgia border counties are the control.

- **Treatment:** `treat = 1` for Florida-side loans, `post = 1` for `report_year >= 2021` (the point at which FL and GA premiums diverge sharply).
- **Estimand:** a reduced-form, intent-to-treat `treat x post` coefficient — not a per-dollar effect of the premium increase itself, which is estimated separately as a first stage (not included in this trimmed sample; see **Scope**).
- **Preferred specification:** two-way fixed-effects DiD (loan and year fixed effects), standard errors clustered by county.
- **Why not IV/2SLS?** An earlier version of this analysis instrumented escrow burden with `treat x post` to recover a per-dollar effect on delinquency. That specification was dropped: Florida border ZIPs also saw a larger home-price/in-migration boom over this period, which affects delinquency directly and not only through escrow costs — a clear exclusion-restriction violation. The current design instead reports the reduced-form effect and the first-stage (premium) effect separately, and treats the equity/migration channel as a confound to be controlled for or stress-tested directly (see `03_robustness.R`).

## Scope of this repository

The full thesis includes additional components not reproduced here: the premium first-stage (county-level, using Keys & Mulder's public premium panel), the ZIP-level in-migration/home-price-footprint construction, and the LaTeX write-up. This repository contains only the **escrow-burden and mortgage-distress analysis** — panel construction, the headline DiD/event-study results, and two robustness checks aimed at the equity/in-migration confound — as a self-contained illustration of the empirical workflow.

## How to run

1. Place the raw extracts in `data/raw/` per the layout above (requires your own DUA-approved CoreLogic access and a Zillow ZHVI download).
2. Run the scripts in order from the repository root:

```r
source("scripts/01_build_panel.R")
source("scripts/02_main_results.R")
source("scripts/03_robustness.R")
```

Figures and LaTeX tables land in `output/`; intermediate panels land in `data/processed/`.

## What this analysis finds (as of the current thesis draft)

Florida border-county escrow burdens (taxes + insurance) rise sharply relative to Georgia's after 2021 — the premium shock visibly lands on homeowners' monthly costs. Despite that, mortgage delinquency and foreclosure event studies show precise nulls: no detectable increase in distress on the Florida side. That null has to be read against a confound — Florida border ZIPs saw substantially faster home-price appreciation over the same period, plausibly building an equity cushion that offsets real strain.

`03_robustness.R` stress-tests that confound two ways. Restricting to loans originated before 2020 (excluding the vintage most exposed to the COVID-era in-migration wave) leaves the headline results essentially unchanged. A more direct attempt — constructing a mark-to-market loan-to-value measure and adding it as a control — is included as a **diagnosed negative result**: adding the control doesn't move the treatment coefficient at all relative to the same regression on the same (LTV-available) subsample without it, and that subsample itself turns out to be unevenly matched across states (58% of Florida loan-years vs. 51% of Georgia loan-years), meaning the specification reflects data-availability selection rather than a real equity effect. It's reported here as a check that didn't pan out, with the reason made explicit, rather than omitted or overstated.
